## 安装方式

最终交付中的 SSH 命令包含整个 ZIP 的真实 SHA-256。先校验 ZIP，再从 ZIP 提取安装脚本执行；不需要另行上传或下载 `.sha256` 文件。

安装脚本内部还嵌入三份源代码、校验器、发布清单和本说明的 SHA-256，并严格限制 ZIP 文件成员、类型和大小。不要直接执行脚本模板 `.sh.in`。

现有 API 路径固定为 `/home/dukaiyu2004/outdoor-fit-api`，只操作 `outdoor-fit-api` 服务，健康检查为 `http://127.0.0.1:3000/api/health`。脚本检查运行进程的实际工作目录、Node 可执行文件、端口及数据文件位置；不读取/输出其他环境配置。
