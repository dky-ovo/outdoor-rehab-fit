- AI 拍照/选图后先本地预览，使用高对比度「發送 / Send」按钮确认后才提交；取消、切换账号、离开页面和重复发送不会误发。
- Android 头像裁剪使用专用深色工具栏与白色裁剪、旋转、返回控件，状态栏修正仅作用于裁剪 Activity。
- 取消 90 分钟闲置自动退出，保留主动退出、密码变更、服务器 token 有效期和吊销验证。
- 后台可新增/修改设施分类双语名称，搜索、分页和查看绑定数量；内建分类编号不变，改名不改器材、媒体 URL 或历史绑定。分类名称用于 APP 展示及 AI 现有资料检索，不替代身体部位安全过滤。

## 倒计时声音与权限

根因：原生播放器使用媒体声道，但此前错误地要求铃声为正常模式、通知许可开启、旧语音通知频道未静音。任一不满足便阻止媒体播放。

现在移除这些不相干的播放条件，使用原有粤语/英文 WAV；仍尊重媒体零音量、勿扰、来电/通话及音频焦点，不提升音量、不改变通知设置。前台服务仍提交系统要求的通知，并区分服务成功与通知实际可见状态。Android 的 `POST_NOTIFICATIONS` 不是启动前台服务的必要条件，但通知抽屉/锁屏可见性仍由系统及用户设置决定。[Android 官方说明](https://developer.android.com/develop/ui/compose/notifications/notification-permission)、[音频焦点](https://developer.android.com/media/optimize/audio-focus)。

计时开始/恢复不再自动请求通知或闹钟权限，也不弹出重复的设置提醒。保留明确的用户开始/恢复授权标记以遵守 Android 前台服务规则。已有成功安排的兼容版提醒不会每次亮屏重排；失败或拒绝的计划可以在回前台后重试检查，但不弹窗。

半程/结束仅一次、结束计时归零、暂停/放弃释放资源、跨账号/旧异步回调失效、错过提示不在亮屏补播等边界均保留。

## 发布与限制

本轮没有上传云端、运行服务器安装、发布 OTA、EAS Build 或提交 TestFlight。Android 语音与裁剪原生修复需要新安装包；原生运行版本已隔离到 1.1.7，不应强制 OTA 到旧 1.1.6/1.1.2 安装包。

本地没有 Android SDK/Kotlin 编译器，也没有受控安卓/iOS 真机。Expo 导出、配置解析、资源与契约测试不等于原生编译或真机锁屏声音测试。需要新 Build 后复核：粤语/英文、铃声静音但媒体有声、屏幕锁定跨半程和结束、系统勿扰/媒体音量零、通话、暂停/放弃、结束后保存、头像白色裁剪按钮。强制结束 APP、厂商省电限制和设备重启后的行为不能承诺与音乐播放完全相同。

后端服务器之前使用 Node 20，而当前 OpenAI SDK 要求 Node 22；本轮未擅自升级服务器运行时。部署仍保留 Node 警告、磁盘空间预检、精确上传路由保护、数据库停机备份和失败恢复；不会自动回滚或删除运行数据库、上传文件或新注册用户。
