# APP 本地操作链路回归报告

检查日期：2026-09-07

本次针对“正数计时器放弃后再次打开异常”开展本地排查，并扩展检查计时、运动日志、导航返回、设施、AI、账号及参与者数据的关联链路。修复范围是现有功能的错误行为，没有调整页面布局或重新设计功能。

本报告记录已实际检查的场景，不代表所有机型、所有网络状态和所有操作组合均已验证。

## 检查环境与方法

- 浏览器检查使用独立的本地服务 `localhost:4180`、内存数据及虚构测试账号。
- 使用 `390 × 844` 窄屏视口，实际点击页面入口、按钮、表单及返回操作。
- 本地测试未修改生产服务器、真实账号或生产研究数据。
- 对重复点击、请求乱序、页面缓存、失焦和切换账号等难以稳定手动复现的情况，增加组件及逻辑回归测试。
- 前端自动测试：20 个测试套件、74 项测试及 1 个快照通过。后端：16 项测试通过。TypeScript 类型检查通过。
- Web、Android 和 iOS 导出验证通过；原生导出用于编译检查（禁用字节码），不是实际设备安装测试。

## 代码排查及回归测试覆盖

### 计时与运动记录

- 检查缓存或失焦的计时页面是否错误拦截其他页面离开，及放弃后的旧状态是否影响重开。
- 检查原生焦点事件延后到达时，重新进入的计时器能否初始化。
- 检查正数、倒数、手动记录的独立入口，现有计时冲突的继续/放弃选择及总结保护。
- 检查倒数暂停、到时完成、重启恢复和浮动计时入口保留设施来源。
- 检查日志详情晚响应、缺失记录、编辑取消/保存的返回、编辑未保存提示及删除失败后的重试。
- 检查离线编辑待同步记录、重叠保存及切换账号时的本地数据隔离。

对应测试包括 `SessionRecordLifecycle-test.js`、`ActiveSessionContext-test.js`、`FloatingSessionTimer-test.js`、`sessionRoutes-test.js`、`SessionLogNavigation-test.js` 和 `sessions-test.js`。

### 导航、目标及参与者数据

- 嵌套页面返回使用已有父页面，避免把子页面替换成新的父页面而累积重复历史。
- 保留主页进入个人化目标和目标设定进入个人化目标各自的返回目的地。
- 目标调整使用串行保存，防止快速修改不同目标互相覆盖；离开后重新读取会等待已排队的保存。
- 个人化目标新增增加防重复提交。
- 参与者使用数据与运动数据分别进入，按参与者、日期、当日数据查看。
- 参与者列表对请求乱序和账号变化进行保护，防止旧账号的晚响应覆盖当前账号内容。
- 核查零目标隐藏、周分钟与天数统计以及历史目标兼容逻辑。

对应测试包括 `ParticipantUsage-test.js` 和 `goals-test.js`。

### 账号、首次引导和提示框

- 登录、注册及找回密码增加同步防重复提交保护。
- 登录页失焦时，不因其他页面完成注册而抢先跳转。
- 登出或切换账号后，旧的登录/资料保存响应及尚未完成的存储写入不能恢复旧登录态。
- 找回密码离页后忽略旧结果；验证码核验期间离页，不再继续发起后续密码重设请求。
- 用户资料离页后不再显示旧保存结果并操作当前页面；照片选择增加重复打开保护。
- 首次引导增加确认防重复及离页后的异步保护，保留原有文案与流程。
- 通用确认框对重复确认进行保护，避免同一操作执行两次或误删下一条排队提示。
- 修复 Web 提示框与已打开表单的叠放顺序：验证提示出现在访客表单上方，可关闭后继续填写，保留原样式和动画。

对应测试包括 `AuthContext-test.js`、`LoginFlow-test.js`、`ForgotPasswordFlow-test.js` 和 `AppAlertHost-test.js`。找回密码测试使用模拟 API，不发送真实短信。

### 设施、位置、收藏与 AI

- 器材使用问题读取 APP 对应资料；太极揉推器的 11 步与设施教学的步骤解析一致。
- 检查推荐入口的设施 ID 是否存在且有效，以及恢复聊天记录时新发送内容是否被旧历史覆盖。
- 检查自定义设施收藏、移除收藏不误触详情及收藏返回。
- 检查位置查询晚响应不会覆盖新查询、位置页切换语言、设施来源保留和无效坐标校验。
- 风险管理中修正了图标库不存在的名称；问卷和安全说明明确返回风险管理。
- Web YouTube 播放器原本缺少原生消息桥，导致播放状态无法传回 APP。复用现有播放器与 HTML 协议，补上仅 Web 的兼容适配器；只接收当前 iframe、当前站点的消息，防止多个视频串流或任意窗口伪造回调，手机端保持原实现。
- 大学研究页面现有的返回“其他”逻辑通过代码核查，未据此宣称外部网站始终可用。

对应测试包括 `assistantEquipmentSearch-test.js`、`AssistantHistory-test.js`、`FacilityFlows-test.js`、`EquipmentMapBack-test.js`、`openExternalMap-test.js` 和 `permissions-test.js`。

Web 视频适配器另有 `YoutubeWebBridge-test.js` 验证实例/来源校验、清理监听及播放器命令范围。

## 验证边界

- 浏览器窄屏检查不能替代 Android 或 iOS 真机测试。
- 未在本环境实际验证 Android 系统返回手势/系统键盘、iOS 侧滑返回/系统相册、后台推送、原生 GPS 权限及外部地图 APP 的唤起。
- Android 返回监听的逻辑测试使用模拟事件，不能证明所有厂商系统行为一致。
- 未调用真实短信发送服务，未对真实账号执行密码重设。
- 未调用真实 DeepSeek 网络服务；已验证的具体器材回复来自 APP 本地资料，相关异步和推荐路径使用模拟数据测试。
- 本报告不表示更新已上传、服务器已部署或手机已收到 OTA。发布情况以实际交付及发布结果为准。

## 复跑命令

前端测试限定在源码测试目录，避免历史临时目录中的非标准 package.json 干扰测试发现：

```powershell
npx jest --runInBand --watchAll=false --silent --roots components contexts utils constants --testTimeout=30000
npx tsc --noEmit
```

后端在 `server` 目录运行 `npm test`。本地浏览器测试服务可用 `node scripts/local-app-audit.mjs` 启动，只监听本机并使用内存数据库，退出后测试服务端数据不保留。
