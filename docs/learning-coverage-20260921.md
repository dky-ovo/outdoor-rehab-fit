# 75% 学习高亮判定（2026-09-21）

## 判定口径

- 收藏页的阅读、观看、收听独立判定，达到 75%（含）才高亮。
- 点击展开、点击播放、跳转至视频结尾不构成学习完成证据。旧版只有 true/false 的记录无法证明 75%，不会继续点亮；不删除原有其他使用统计。
- 阅读范围是当前语言下实际存在、可展开的介绍、物理治疗、职业治疗、中医（仅启用时）、照顾者及使用步骤文字。按各栏目字符数加权，已展开文字的纵向可见覆盖去重累计；同一可见区域必须相隔约 1 秒连续采样且位置稳定。快速划过、未展开、屏幕外、后台及图片弹层不计入。iOS 底部标签遮挡区会扣除。
- 这是对可见阅读行为的估计，不能证明用户理解了文字，也不追踪眼球。未用页面停留时间或滑到最底部直接认定完成。
- 上传视频及旧 YouTube 视频按实际前台连续播放的位置区间累计。暂停、缓冲、拖动、后台及超过 2.5 秒没有连续采样的空档不推算为观看。重复播放相同区间不增加比例。
- 预录音按实际前台播放区间去重累计；TTS 按已播报字符（非“即将播报”的单词）及已完整播报的短句累计。无词边界回调的语音引擎仍可凭短句实际结束回调累计。TTS 不再误计为阅读。
- 收听可由当前语言预录音达到 75%，或所有可播报文字栏目按字符加权达到 75%；两种不同媒介不相互叠加。
- 同一账户跨次进入会保留区间。文字版本、视频来源及中英语言不互相拼接；收藏仅匹配当前内容签名，旧版本已完成不会误点亮新版本。
- 写入按明确的用户命名空间排队合并，未初始化账户不读写。切换账户后旧组件/异步回调不写入新账户。重复可见区间不会反复落盘。

## 验证

新增纯函数和实际组件测试覆盖：74.99% 与 75% 边界、独立高亮、多栏目权重、跨次恢复、并发更新、账户切换、旧 boolean、版本与语言变化、可见区域/快划/底栏遮挡、视频拖动及后台、TTS 中止与延迟回调、录音拖动、旧 YouTube 异步进度。

保留既有视频研究事件接口，不将每秒学习采样上传为研究事件。真机语音引擎/播放器回调行为仍应在 Android、iOS 上复核。
