# 后台用户反馈／文件存储白底布局修复

## 范围与原因

两个独立页面复用了横向概览卡片的 `styles.panel`（`flexBasis: 350`）。在纵向 ScrollView 中，它成了高度约束，子内容可以继续溢出，但白色背景停在约 350 像素处。

仅给文件存储、用户反馈外层加 `fullPagePanel`：`flexBasis: auto`、`flexGrow: 0`、`flexShrink: 0`、`width: 100%`、`minWidth: 0`。保留白底、圆角、内边距及所有按钮、权限、接口和操作逻辑。没有修改其他概览卡片，也没有以裁切或固定高度隐藏内容。
