# AI 助手中医原文补充（2026-09-16）

后续用户要求将中医解释移到上方回答正文；该调整已在本地完成，最新行为和验证见 `docs/ai-tcm-answer-prose-20260916.md`。以下保留首轮卡片版本的工作记录。

## 本轮范围与结果

已修改本地 APP 与后端：为已有设施推荐/教学入口增加简短“中医学角度”原文；用户提供的截图仅参考内容组织，不复制“首选”排名，也不新增外部医学建议。未修改设施原始说明、分类或现有后台中医开关。

- 当前默认资料为中文 10 项、英文 9 项。内部 ID `0、4、6、8、10、16、19、20、22` 有双语中医内容；`28` 石春路仅有中文。Word 编号 17 对应内部 ID19“肩关节伸展”，不是内部 ID17。
- 只从当前语言的已启用 `tcmTip` 提取 1–2 句完整、连续的原文，中文最多 220 字、英文最多 550 字。不硬截句子，不自动翻译，不从其他语言补空白。
- 摘录不带首选/最佳等排名，不摘取治愈、具体用药和赤脚操作句；不把同段警告、否定或后置条件剥离。石春路只取背景首句，不能因此作为膝痛器材推荐。
- 在推荐理由下方、设施教学入口上方显示独立中医栏目与来源/使用边界。图片、原推荐理由及 `from: ai` 跳转不变。照片识别须先确认，才显示补充内容。
- 直接询问某设施的中医解释时返回短原文及入口，不依赖 DeepSeek；主回复已经包含摘录时，卡片不再重复。
- 中医摘录只补充已有卡片，不新增设施、不改变推荐顺序。症状依据本身已经引用中医时不重复补充。
- 新增“肩周炎／五十肩／冷冻肩／frozen shoulder”检索识别，继续使用 APP 专业说明核对。实际双语数据返回 ID0、5、19 的物理治疗原文，其中 ID0、19 增加中医摘录，ID5 没有中医资料，不补造。
- 膝痛仍仅返回有原文依据的 ID4、10、11；仅 ID4、10 有附加中医说明，不加入 ID28。

## 后台与旧版本保护

- 沿用后台既有字段与开关，不增添重复编辑入口。非空维护文本覆盖默认文本，关闭开关后停止展示。内置字段空串仍沿用项目已有的默认内容回填规则；要隐藏该栏目使用关闭开关。自定义设施和本来缺少英文的设施不会借用中文。
- 不接受客户端/模型传入的中医摘录，按当前可信目录重新生成。
- 服务端普通设施描述也不再使用旧客户端拼接的描述，改用已维护字段及 APP 原文快照；中医内容仅走独立受控路径。避免旧 APK 把已关闭中医文字再次回显。
- 旧对话中的直接中医正文按稳定设施 ID 重建，覆盖改名、下架、泛指问句、问题已被历史长度限制截断等情况；原始存储记录不删除、不改写。
