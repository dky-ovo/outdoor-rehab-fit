# AI 推荐保留一个简短解释（2026-09-17）

## 最新要求

在单句详情提示的基础上恢复少量解释：正文举例一个器材，其他内容放入“查看详细说明”。本记录取代同日 `ai-neutral-preview-20260917.md` 对常规推荐预览的描述。

## 实现

- 按现有推荐顺序选取一个有已验证专业证据的器材，显示名称和完整短摘录，下方提示查看详细说明及器材教学。
- 仅使用当前物理治疗、运动学或职业治疗字段中，与当前回答一致的证据；不生成新疗效，不从其他段落拼接内容，不改变器材推荐与排序。
- 中文摘录最多 100 字符，英文最多 350 字符。过长的摘录不截断，选择下一个合适的器材；没有合适摘录时保留中性详情提示。只有中医证据时不拿无关的专业说明代替。
- 完整说明（含其他器材、中医内容和注意事项）仍在独立详情阅读页，原有器材图片及教学入口不变。
- 特定禁忌与条件、未知正文、直接使用步骤和独立中医查询沿用既有保护逻辑。顶部固定安全提示不变。
- 仅改变展示；不改历史存储或发送给 API 的完整内容，不改后端或原生代码。

## 验证

- 预览逻辑、聊天历史、滚动与详情组件：4 套、148 项测试通过。
- 覆盖中英文肩周炎/膝痛、一个例子、长证据不截断、专业字段选择、仅中医证据、历史恢复、详情打开及关闭、器材跳转、完整内容与安全提示保留。
- TypeScript 检查通过。
- 未执行本轮真机点击、三端导出、OTA、Build 或后端部署；手机需发布兼容的前端 OTA 才能获取修改。
