# AI 推荐自然回应与简短中医补充（2026-09-17）

## 最新要求

取消固定“例如”开头。推荐回答先回应查阅需求，再介绍一个器材的作用；有相应中医内容时补充简短解释，最后引导查看全文或下方器材教学。本说明取代同日单例预览记录中的固定开头设计。

## 实现

- 推荐回答使用六组中英文开场、三组详情引导语，按当前对话中可整理的推荐回答顺序轮换；部位和器材名称随当前问题与已验证推荐变化。不是无限生成互不重复的医疗建议。
- 使用“建议先了解/查看教学”等措辞，不把用户描述当作确诊，也不宣称器材一定适合其症状。
- 仍只展示一个完整的专业短摘录，中文最多 100 字符、英文最多 350 字符；不改变证据或推荐排序。
- 可补充同一器材已开启、当前语言已有的中医内容，最多一个完整句子，中文最多 90 字符、英文最多 240 字符。重新从当前目录核对，不信任模型附带的中医片段，不借用其他器材的说明，也不截掉后续条件或警告。
- 没有合适短摘录时保留详情引导，不编造作用。空白英文中医内容不借用中文或自动翻译。
- 其余解释保留在原有独立详情页；图片、器材入口、推荐排序和顶部安全提示不变。
- 直接使用步骤、独立中医查询、安全拒绝、警告及无法核验的正文继续沿用原有保护逻辑。
- 仅改变前端展示；完整回答、历史保存和 API 上下文不添加展示措辞或轮换标记。没有新增模型请求。
