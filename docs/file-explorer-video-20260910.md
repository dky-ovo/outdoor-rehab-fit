# 文件资源管理器及视频显示更新（2026-09-10）

## 本次修改

- 网页后台接入 SVAR React File Manager 2.6.0（MIT），支持文件夹、路径导航、双击、右键菜单、列表/图标视图、批量选择、复制/剪切/粘贴、重命名及回收站。文件列表每页 20 项，搜索覆盖所有文件夹。目录树按当前已加载页面和祖先展示，不一次加载全库。
- 保留原有本地文件/整个文件夹上传、分类、归档、恢复和设施教学媒体选择功能；权限由原有服务器接口校验。
- 移动和重命名仅改变逻辑目录/名称，不改变原视频 URL。复制创建新 UUID 和新文件，校验字节哈希；被 APP 引用的内容不允许删除。复制一次最多 1 GiB，避免意外占满服务器。
- SVAR 是前端组件，不是额外的网盘或 Codex 插件。文件继续存储在现有服务器的持久磁盘；本次不新增向第三方云盘的同步或公开权限。
- APP/Web 直接视频按原视频比例适配可用宽度，移除固定播放器高度带来的额外黑边；不裁切教学动作，不修改视频原片。原片内已有的黑边保持不变。
- APP 内移除下载菜单、网页长按保存及打开外部下载链接的入口。公开播放接口忽略 `?download=true`，仅授权后台下载接口返回附件。后台管理员的“下载到电脑”保留。
- 此下载限制不是 DRM，不能保证阻止录屏、技术抓取或自行保存可播放的流。

## 文件及视频保护

- 沿用已审核的 57 个原文件：54 个正式中英文教学视频、2 个归档旧视频、1 个私有 Word 文档。
- 54 个中英文绑定及原始哈希不变；缺少新版视频的编号 13、27 不强行替换。导入记录保护后续后台人工修改及删除，不因重复安装重置。
- 不重建生产数据库，不重设用户、密码或后台权限，不自动清理旧包、日志、备份或上传文件。

## 本地验证

- 前端 69 个测试组、762 项测试及 1 个快照通过；后端 90 项测试通过，0 跳过；部署及组件真实 Store 等脚本测试 51 项通过。类型检查及 Android/iOS/Web 导出通过。
- 浏览器使用 127.0.0.1:4187 的隔离内存数据库及测试账号，没有使用或修改生产用户数据。
- 实际验证文件夹双击、根路径返回、真实分页（24 项分为 20+4）、本页全选、真实竖向视频加载及比例。测试片为 810×1080，播放器元数据正确，下载控件为 `nodownload`。
- 设施编辑的中文视频选择窗口可以正常打开目录、选中 `1.mp4`、返回编辑并取消，测试未保存设施更改；本地 SVG 目录/文件图标及导航箭头已通过浏览器截图确认。
- 最终预览及确认窗口使用 body Portal，不受后台滚动容器裁切。桌面 1440×1000 实测 `4.mp4` 显示约 488×650，标题、关闭按钮和播放控制栏均完整可见。
- 已确认中文 `1.mp4` 原片尺寸为 1280×720，内部包含两侧黑边。播放器尺寸与 16:9 一致，这部分黑边不是固定高度造成的；本次保留原片及教学标注，没有自动裁剪。
- 视频进度既有事件与校验保持，尺寸事件不会冒充观看进度；保留后台暂停、页面退出、错误重试、过期播放器事件隔离。
- 导出成功不等于手机真机测试；Android/iOS 的长按、全屏播放和系统播放器行为仍需安装后复核。

## 部署包

完整包：`outdoor-fit-file-explorer-video-20260910-update.zip`。

安装脚本：`install-file-explorer-video-20260910.sh`。

- 完整包含 API、Web、原始种子、路径/归档/运行状态校验及校验和；不依赖旧更新包，也不覆盖旧本地 ZIP。
- 先在 `/run` 提取并校验小文件和空间清单，通过磁盘空间预检才解压大型载荷；依赖安装后、备份前再次检查。
- 保留依赖缓存、原数据库及媒体备份空间，并给各磁盘预留至少 2 GiB 与 10% 估算余量；不足时停止，不自动删除任何数据。
- API、其关键子目录、staging 和 backup 必须同盘，确保恢复所需移动操作不跨盘。独立媒体上传盘仍按实际磁盘检查空间。
- 包含已验证的 Certbot TLS include 兼容修复，只提高精确上传接口大小限制，不扩大认证权限。
- 失败时恢复程序文件；不自动回滚运行数据库、上传及新注册数据。停服后的数据库备份供必要时人工恢复。
- 当前服务端 OpenAI SDK 声明要求 Node >=22；已知服务器为 Node 20。本轮不擅自升级运行环境，安装脚本会明确提示。该运行时兼容问题仍应另行处理。
- npm 审计仍报告现有依赖风险（本轮安装时共 38 项，未发现归属于新增 SVAR 包的项目）；没有执行无关的框架升级或 `npm audit fix`。
