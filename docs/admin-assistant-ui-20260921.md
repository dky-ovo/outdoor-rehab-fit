# Word 导入弹窗与后台 AI 助手界面（2026-09-21）

## 本轮范围

- 户外器材维护的 Word 导入改为入口按钮，点击打开独立、可关闭弹窗；入口与“添加设施”放在同一操作区。
- 弹窗标题和关闭按钮固定在顶部，正文限定高度并可滚动。关闭放弃未提交预览、取消读取并隔离晚到响应；确认保存期间暂禁关闭，以免把已发送的写入误称取消。
- 导入字段选择、二次确认、历史旧内容、新旧差异及 AI 草稿转交保持。只改界面，不更改固定编号匹配或导入数据库逻辑。
- 后台侧栏、标题及权限文案统一为“AI 助手”，界面参考用户图片的浅蓝背景、中央欢迎区、大输入框和圆形发送箭头。
- 仍然先预览发送范围，再明确确认发送 DeepSeek；不新增网络搜索、自动写库或用户资料访问权限。测试只使用模拟 AI。

## 麦克风语音：尚未上线

用户已确认 APK 1.1.9 / Build 13、Android API 31，语音组件可用、系统语音识别服务不可用。现有 expo-audio 的录音功能直接使用麦克风，不依赖 Google 的系统识别服务。但录音本身不是语音转文字，仍需单独识别引擎。

已询问选择自家服务器识别或云端识别 API；两者的服务器资源、音频去向与费用不同。收到选择并完成识别服务接入前，不把手机切换到未配置的音频上传接口，不上传语音给新的第三方。

此 Web 包不修复手机语音，也不要求发布手机 OTA。上一轮语音行为保持不变。预计已有 expo-audio 和麦克风权限可供 runtime 1.1.9 使用，但不能替代对实际 APK 和真机录音的验证。
