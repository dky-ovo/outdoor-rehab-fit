# Android 本地图片更新交付记录

本次将公开器材主图和教学 GIF 保存到手机应用的私有持久目录，收藏、器材列表、教学详情与 AI 推荐卡片共用本地文件。首次安装或更换图片时仍需联网下载；已有文件后再次打开直接使用本地文件。不会把旧 URL 的照片作为新图的加载占位图。

收藏记录原本就按账号保存在手机。本次在登录、恢复会话及回到前台时，后台检查公开器材目录，并优先下载收藏主图；不会等待整个下载队列结束才显示页面。短时间内的页面切换共用目录请求与结果，避免每次点击重复请求目录。

手机先恢复已经保存且带令牌的会话，再后台核对服务器。新登录、服务器权限及删除账号的验证继续存在；此修改不代表数据库暂停时所有联网功能都能立即完成。

| 位置 | 保存内容 |
| --- | --- |
| RDS | 服务器业务记录、账号与权限、器材内容和媒体路径等元数据；本次不调整其结构 |
| ECS | 原始图片与视频文件；本次不移动或修改服务器文件 |
| 手机 | 按账号隔离的收藏等现有本地记录，公开器材目录，以及可复用的主图/GIF 文件 |

图片文件预算为 256 MiB，单文件最多 16 MiB，下载并发上限为 2。磁盘不足时保留正在显示的文件，优先为收藏腾出空间；无法缓存的图片仍可联网显示。不批量下载视频、聊天附件或其他私密文件。卸载应用或清除应用数据后需重新下载。

使用 `expo-file-system/legacy` 的持久目录，区别于系统可自动回收的临时缓存，接口依据 [Expo SDK 54 官方文档](https://docs.expo.dev/versions/v54.0.0/sdk/filesystem-legacy/)。已检查现有 Build 17 APK 的实际原生模块注册表，可以使用此次所需模块，无需为本次功能另装 APK。

## 发布

在这台电脑的 **Windows PowerShell** 执行，不是在 ECS：

```powershell
cd "D:\polyu work\outdoor-rehab-fit-anesthesia"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\android-build17-local-images-ota.ps1" -Action Publish
```

脚本固定发布 Android 1.2.3 / Build 17、runtime `1.2.3`、`preview` 通道，使用已导出的产物，不重新打包、不发布 iOS。发布后保持联网打开 App，待在线更新下载完成并重新打开后生效；首次图片保存也需要联网时间。不同 Expo 登录账号或发布权限问题需要使用原项目的有权账号解决。

本次仅准备客户端更新，尚未发布到用户手机，未重新部署后端。服务器旧图片自动清理属于此前独立的 v4 后端补丁；此前只收到 v3 暂存失败的输出，不能据此认定服务器自动清理已经启用。
