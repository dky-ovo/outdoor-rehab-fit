# AI 简短回答与独立详情阅读（2026-09-17）

## 本轮改动

上一版只隐藏部分专业段落，固定导语、重复器材名称和多段中医文字仍很长；倒序聊天列表中的展开/定位还增加了交互复杂度。本轮替代该内联展开方案。

- 普通、可验证的设施推荐默认显示：一句中性导语、最多一条关联器材的中医短句、一条简短安全提示。
- 器材名称、图片及设施教学入口保留在下方卡片，不再在简短正文中重复列出全部名称。不改变器材选择或排序。
- 只使用当前已启用、当前语言、已验证的中医资料；取完整短句，不调用模型改写，不补充网络医疗建议。没有合适中医句子时不硬加。
- 完整正文保存在独立详情阅读页。“查看詳細說明 / View details”打开全屏 Modal，独立 ScrollView 从本条说明开头阅读，顶部与文末均可返回对话，Android 系统返回也关闭详情。
- 移除聊天界面的内联展开状态与单元高度/滚动定位联动。打开详情不改变气泡高度、不调用列表滚动、不把摘要写入历史或 AI 上下文。
- 详情使用安全区、可换行的大字和至少 52 高度的返回按钮；聊天里的详情按钮也放大。不通过缩小字号减少内容。
- 详情按消息 ID 取当前完整文本，离开页面、切换账号/语言/登录状态后关闭。新回答到达不覆盖正在阅读的旧回复。
- 短回答不增加详情按钮。直接使用步骤、照片确认、地图、错误及风险拒绝保持原流程。原文中的明确禁忌、否定或适用限制不得为字数目标随意截断，必要时仍完整展示。

## 真实数据长度检查

字符数包含换行；是本地资料样例，不代表每种回答都固定此长度。

| 示例 | 完整正文 | 默认简短正文 |
| --- | ---: | ---: |
| 中文肩周炎 | 470 | 110 |
| 中文膝痛 | 543 | 121 |
| 英文肩周炎 | 1,766 | 367 |
| 英文膝痛 | 1,715 | 321 |

中文肩周炎默认正文样例：

```text
可先了解下方 3 項器材的教學。

中醫小知識 · 太極揉推器
練習推手時，要將意念、呼吸和動作三者緊密結合，做到「以意念引導氣息，以氣息帶動身體」。

僅供參考，並非治療建議。有疼痛時先由醫護評估，並閱讀完整注意事項。
```

这只是教育资料预览，不代表对症状作出适用性或治疗判断。全部专业引用及其他中医内容仍在详情中。
