# AI 器材推荐与连续追问修复（2026-09-22）

## 问题及修复

截图中的问题不是单纯 DeepSeek 模型不稳定：手机发送、后端症状分支和历史显示层均有旧的本地提前返回规则，普通疼痛提问实际上可能没有进入 DeepSeek。“腿痛”“膝盖”“走路痛”及“继续说明”的短回复也会丢失已提供的部位。

- 普通症状查询改为实际调用现有后台配置的 DeepSeek HTTPS Chat Completions 接口。
- 从当前已发布的 APP 教学说明提取有对应部位及明确正向说明的候选内容，交由 DeepSeek 选择和排序 1–3 项。候选池不再限于本地固定前三项。
- 输出中的器材 ID、说明字段和完整引用必须通过原文核验。DeepSeek 不能通过自由编写的疗效、处方或分类标签代替原文证据。
- 下肢、膝部、足底不再混为一谈；简繁体器材名称一致识别。未找到依据时不补凑器材。
- 连续问题保留已明确部位；切换话题、问候或独立位置查询不继承旧症状。只在确实缺少部位时询问。
- 紧急危险症状仍直接给出安全提醒，不等待模型，不推荐器材。这是资料查阅功能，不是诊断或个体适用性判定。
- 有效新版回答不再被前端改写为旧的固定追问。内容下架或依据更改后，旧正文及卡片同步失效；中医附加说明随现有维护内容重建。
- 请求失败、未配置密钥、超时或模型输出不合格时明确失败并保留重试路径，不伪装为已成功调用 DeepSeek。
- 本轮不改变语音播报、不恢复语音输入，不修改参与者设施教学进度功能。

## 隐私及调用范围

发送给 DeepSeek 的仅是当前用户提交的本轮问题、有限的相关对话文本，以及已发布设施的名称和说明。没有授予读取用户数据库、账号、密码、API key、其他用户记录或后台文件的权限。API key 仅由服务器用于认证，不放入提示词或返回 APP。

模型输出只决定候选顺序、选项和有限的介绍风格；健康相关事实由已维护的完整原文提供，不采用自由生成的治疗结论。接口有总超时、最多两次生成及证据变化复查。

后端和网页版均需更新。手机还需发布兼容当前 runtime/channel 的 OTA，单独更新后端无法移除旧手机上的本地拦截。已安装当前 1.2.2 Android Build 16 的手机无需为本轮重新 Build。

本轮未自动上传、部署服务器、发布 OTA 或发起新 Build。现有历史不自动重新请求模型，更新后请重新发送问题验证。
