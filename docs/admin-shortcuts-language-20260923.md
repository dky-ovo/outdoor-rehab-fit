# 后台内容管理快捷入口语言切换

日期：2026-09-23

## 问题与范围

后台顶部已有简体、繁体及英文切换，但内容管理快捷入口的标题、总说明和四张卡片的名称、说明原先写死为简体中文。本轮将它们接入同一个后台语言状态，另补齐「APP文字与说明」二级菜单与面包屑的三语文案。

- 新文案集中在 `constants/AdminWorkbench.js`。
- 保留四个入口的顺序、图标、权限过滤和跳转目标，不调整界面样式。
- 切换后台界面语言不会自动翻译或保存 APP 内容，也不会重置未保存的设施编辑草稿。
- 不修改 API、数据库、账户、上传文件、依赖或原生配置。
