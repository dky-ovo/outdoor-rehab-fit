## 满屏章节与响应式原则

- 主要章节使用 `min-height: calc(100svh - var(--nav-height))` 建立视窗尺度，并通过内边距、列比例和图文尺寸安排内容。使用最小高度而非固定高度，团队等长内容可自然撑高。
- 大屏保留原版各章节的图文列数、先后顺序及主次关系；窄屏按原有响应式逻辑切为单栏，按钮可换行，字号和图片不以整页缩放处理。
- 使用浏览器原生滚动；原有导航指向真实锚点，不新增侧边章节导航轨道，不拦截滚轮或强制翻屏。
- 光晕、阴影和位移通过 CSS 变量及原生事件实现。装饰层设为不可接收指针事件，触屏无需依赖 hover。
- 尊重 `prefers-reduced-motion`，关闭不必要的位移、缩放和指针跟随效果；禁用 JavaScript 时仍能阅读内容和访问链接。
- 使用原有 HTML 语义和真实链接，保留清楚的键盘焦点；无须为本轮视觉打磨引入 tab、筛选或面板切换语义。
