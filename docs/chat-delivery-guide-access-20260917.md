# AI 助手发送恢复与只读资料检索检查（2026-09-17）

## 本轮范围

- 修复输入问题、点击发送后，接口挂起或返回空内容时没有有效反馈的问题。
- 为 DeepSeek 增加 APP 已发布设施教学的只读搜索与读取工具；不授予管理员权限。
- 保留现有聊天样式、简短摘要、详细说明、器材入口、症状匹配及中医内容限制。
- 不更改后台已保存的模型或 API Key，不发布 OTA，不部署服务器，不执行新的原生 Build。

## 已确认的代码问题

1. AI 请求原先没有超时，网络请求或 JSON 响应读取一直未完成时，发送状态无法结束。输入框已清空，用户容易认为问题丢失。
2. HTTP 成功但正文缺失、JSON 格式错误或文字为空时，原流程可能生成空白回复。
3. 消息 ID 只依赖毫秒时间，在同一毫秒内连续操作可能重复。
4. 本地教学检索原先在异常恢复范围外，异常时可能留下发送锁。

以上问题通过隔离测试复现；尚未取得用户出问题时的手机日志，不能断言其实际反馈全部由同一个原因造成。

## 发送恢复

- 前端 AI 请求最多等待 65 秒，同时约束请求及响应正文读取，即使传输层忽略中止也能退出等待。
- 空白或非字符串回复视为失败；显示可读错误信息，不再插入空白 AI 回复。
- 用户问题保留在聊天记录中。失败时输入框没有新草稿才恢复原问题，避免覆盖用户新输入。
- 防止重复点击发送，消息 ID 加入序号；切换账号、语言或登录凭据时忽略旧请求结果。
- 本地检索和远程发送统一进入异常处理，确保释放发送状态。

## DeepSeek 查阅边界

- 允许搜索当前已发布设施的名称、公开分类与教学文字。
- 允许按设施 ID 读取使用说明、运动学、物理治疗、职业治疗、中医、照顾提示；中文、英文按当前语言分别读取。
- 中医栏目关闭、设施停用或删除后，不作为可读取资料；读取期间内容变化则拒绝继续返回旧资料。
- 不开放用户账号、密码、密钥、管理权限、其他人的聊天或运动记录、后台文件库、网络浏览及任何修改能力。
- 不信任手机请求中伪造的教学内容或权限字段。资料从服务器的发布目录和维护内容获取。
- 每次请求最多 3 次模型调用、4 次工具调用，总时限 55 秒；长字段分页读取。
- 根据 [DeepSeek 思考模式与工具调用说明](https://api-docs.deepseek.com/guides/thinking_mode/)，同一工具调用过程按要求回传供应商生成的 `reasoning_content`；不向 APP 返回或持久化这段供应商推理记录。历史聊天作为标记过的参考上下文传入。
- 教学内容通过已实际读取、仍然有效的资料引用重建，不把模型自行生成的操作方法作为教学原文返回。无有效引用时询问用户要查阅的器材和栏目。
- 工具调用或资料引用都会触发输出核对，不依赖本轮问题是否包含“使用”等关键词。补充“再讲详细点”“Tell me more”等连续追问识别，并保留前文症状及急症限制。
- 用真实的用户／助手成对历史连续测试 8 轮。原始主题超出上下文窗口或历史为空时，省略式追问仍须核对资料；没有足够上下文则澄清，不退回未经核对的模型教学。
- 保留症状、急症及身体部位约束。中医仅使用现有受限摘录及说明，不推导新的疗效或适用症状。

## 上线后建议真机复测

1. 输入普通问题后点发送，确认问题显示在聊天记录中、等待状态可见，成功时显示非空回复。
2. 断网发送后确认提示失败；恢复网络后重试。等待时输入另一段草稿，确认失败恢复不会覆盖它。
3. 询问一个设施的使用方法，随后说“再讲详细一点”，确认内容、器材入口与后台当前已发布资料一致。
4. 用没有中医说明的设施、关闭中医栏目或缺少英文说明的设施查询，确认不补写不存在的内容。
5. 快速重复点发送、切换语言或重新登录后，确认不会重复提交或混入旧账号的回复。
