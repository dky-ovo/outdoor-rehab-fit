# AI 推荐正文精简与展开说明（2026-09-17）

## 本轮修改

- 推荐文章默认保留器材名称、简短说明、现有的一至两句中医解释和安全提醒；较长的专业说明可通过“查看完整說明 / View full explanation”展开，再次点击收起。
- 卡片只显示图片、名称和设施教学入口。原卡片中与正文不重复的说明移入正文，额外安全提醒不随卡片精简而消失。
- 不缩小原有正文字号。展开按钮支持换行，最小触控高度为 48，并提供按钮及展开状态的无障碍语义。
- 使用方法、完整步骤、直接中医查询、照片识别/确认、地图、错误及无证据拒绝回答不折叠。短回答不增加多余按钮。
- 内容仅做显示处理，不让模型重新概括医疗解释。折叠前核对现有文章是否与当前设施资料的确定性重建结果完全一致；只折叠追加的完整专业段落，不截断句子。
- 含警告、否定或限制条件的专业段落保持完整可见；原始回答主体及中医摘录和注意事项始终保留。未知模型长文宁可完整显示，不做不可靠的摘要。
- 展开状态只保存在页面内，与消息 ID 和当前显示内容对应；账号/语言改变时清空，维护内容改变时不会复用旧正文状态。
- 展开和收起不自动滚动、不创建过渡动画；会取消尚未执行的网页新消息位置补偿，避免内容展开被误当成新消息插入。
- 消息显示结果按消息、语言和设施资料缓存，输入文字或展开时不重新解析全部文章。
- 保留前两轮聊天底部定位/历史滚动修复及来源措辞清理。设施推荐选择、顺序、跳转、持久化消息、API 历史及后端均不改动。
