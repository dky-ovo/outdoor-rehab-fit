# AI 对话历史与登录隔离（2026-09-22）

## 已实现

- 删除中英文“请安装新版 APP 才能使用朗读”的提示，不改变自动朗读开关、单条朗读及停止功能。真实的声音不可用或播放失败仍提示原因。
- 聊天顶部新增“新对话”和“历史对话”。历史按最近时间排序，可进入完整文字阅读，返回列表或关闭；历史不自动朗读，不能恢复成当前对话或直接发送。
- 每次登录、注册生成独立的本地对话会话标识。明确退出登录后，再登录即空白新对话；账号相同、服务器 token 相同也不会接续旧对话。
- 同一次登录下，只离开 AI 页面或重启 APP 会恢复当前对话；修改个人资料或刷新 token 不会创建另一段历史。
- 旧版记录仅迁入只读历史，原存储不删除、不覆盖，也不自动带入新对话。新版历史保留经过白名单过滤的资料依据；设施说明更新时仍会重新验证引用，避免显示失效的推荐依据。
- 未加载完记录时禁止输入和发送；退出、换账号、新对话后丢弃旧网络结果。开始新对话前先保存当前内容，保存失败不会清掉尚未保存的文字，连续双击也不会创建重复会话。

## 保存及隐私范围

历史保存在当前设备（Web 为当前浏览器），按账号及界面语言隔离，不新增云端聊天同步。卸载、清除应用数据、清除浏览器数据或更换设备不能保证保留。

每段沿用最近 80 条消息的上限（用户问题和 AI 回答分别计一条）。每个账号及语言最多 100 段，并有总存储容量保护；达到容量或读写异常时显示保存失败提示，不为腾出空间静默删除旧会话。

历史查看入口不调用 DeepSeek。新请求只使用当前段最近的对话，不会搜索或拼接归档历史。存储模块不接受账号密码或 token，不新增向模型发送用户资料的权限。
