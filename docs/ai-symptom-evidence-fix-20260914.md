# AI 助手膝痛错误推荐：检查与修复

日期：2026-09-14。范围：本地代码、隔离数据库及浏览器回归；未操作生产服务器、发布 OTA 或提交新安装包。

## 原因

团队测试语句为“膝頭哥痛可以用什麼戶外儀器”。旧服务端和客户端都把膝、踝、足、腿归入宽泛的 `lower` 分类，并对疼痛查询中的 `relaxation` 加分。石春路属于下肢／放松，因此排在了真正含膝痛说明的伸展器材前面。

服务端还会在模型没有提供推荐时补入分类卡片，客户端收到空或无效推荐时也会再次补卡。因此即使正文不建议自行使用器材，卡片仍可能声称依据 APP 内容。该现象有确定的程序原因，不能只归因于模型随机性。

## 与 APP 原文核对

以下编号为 APP 内部 ID，不是 Word 文档的设施编号。

| APP ID | 设施 | 核对结果 |
| --- | --- | --- |
| 4 | 全身伸展运动器（下肢伸展） | 中英文物理治疗说明明确提及膝关节炎患者及膝关节痛。 |
| 10 | 小腿伸展 | 中英文物理治疗说明明确提及膝关节炎患者及膝关节痛。 |
| 11 | 平衡锻炼（半前蹲） | 同样有明确的膝关节痛原文，可作为资料入口。 |
| 28 | 石春路／足健径 | 中英文专业说明没有膝痛效益依据；不能仅凭下肢／放松分类加入。 |

4、10 的相关段落位于旧版 1800 字符描述范围内，本次误配不是这两段被截断造成的。不过合并截断描述会失去栏目边界，新逻辑不再把它当作疼痛依据。

## 修改

- 症状查询使用确定性的 APP 原文检索，不让 DeepSeek 生成疗效说明或推荐理由。
- 区分膝、足、踝、髋、肩、腕等具体部位。只有宽泛“腿疼”而部位不清楚时先询问，不套用整个下肢分类。
- 原文必须在专业说明字段中明确提及对应部位、不适及肯定的相关作用。步骤中的屈膝、警告、否定、不确定表达、关闭的中医学栏目均不能作为推荐依据。
- 卡片显示栏目名称和完整的支持句，保留原文提到的情况，例如“膝关节炎”。明确区分资料查阅入口与个人医学适用性判断。
- 不硬编码石春路黑名单；后台维护的有效专业说明会影响结果，分类本身不能制造依据。
- 无依据、下架或已删除的设施不显示。最多三项，但只有两项依据就显示两项，不凑数。
- 服务端使用与 APP 逐字段一致的 29 个设施双语说明快照，加上后台维护覆盖；不信任客户端提交的名称、分类或描述作为健康依据。
- 症状判断位于普通命名器材说明之前，覆盖英文 `hurts / sore / stiff` 及带有“附近／位置”的症状问题。
- 删除成功响应的空推荐分类兜底。401、429 也不会被本地推荐掩盖；网络错误仅保留非症状的分类参考。
- 历史症状回复展示时按当前资料重新核对，原始存储记录和用户消息保留；更正后的展示内容才进入后续请求历史。照片确认和地图动作保留原流程。
- 连续追问最多追溯最近八条用户消息，保留具体疼痛部位和请求；遇到新话题、问候或普通地图问题则停止继承。新点名的器材必须用它自己的说明核验，不能借用上一项器材的依据。
- 纯使用方法查询仍保留 APP 原文，例如太极揉推器的 11 步说明。未修改页面布局、器材教学原文或详情返回路径。

## 验证

- 前端：82 个测试套件，962 项通过，1 项快照通过。
- 服务端：126 项通过，2 项依赖完整原始媒体种子的既有测试跳过，0 失败。其中新增症状专项测试 28 项全部通过。
- 新增症状专项覆盖粤语、简体、英文、两项不凑三项、否定／警告、后台更新／下架、双语隔离、无 API Key、伪造客户端数据、认证与普通查询回归。
- 症状 HTTP 测试采用内存数据库与本机随机端口；DeepSeek 初始化及完成接口调用次数均为零。
- `node scripts/generate-assistant-evidence-catalog.cjs --check`：29 项双语原文与 APP 一致。
- `tsc --noEmit`：通过。
- Expo Android、iOS、Web 本地导出：通过，产物位于 `workspace-artifacts/ai-symptom-evidence-fix-20260914/export`。这不是新的 APK、IPA 或已发布 OTA。
- 浏览器 390×844 本地验证：输入团队原问题，显示 4、10、11 的逐字来源，没有石春路；打开小腿伸展卡片后展开物理治疗栏目，原文一致；点击详情返回箭头后回到原 AI 会话。

- `utils/assistantEquipmentSearch.js`、`app/(tabs)/chat/index.js`：客户端检索、响应和历史展示处理。
- `server/test/assistantSymptomEvidence.test.js`、`utils/__tests__/assistantEquipmentSearch-test.js`、`utils/__tests__/equipmentGuideEvidence-test.js`、`components/__tests__/AssistantHistory-test.js`：专项回归。

## 发布和限制

本次修改尚未部署。需要同时部署后端并更新 APP 的 JavaScript（兼容安装版本可通过 OTA）；只更新服务器不能消除旧客户端自身补卡的逻辑。后台原文快照必须与服务端代码一并打包。

这是保守的资料检索，不是医学诊断、个人用药或运动处方，也不证明某器材适合某位用户。尚未在实体 Android／iPhone 上复核；自动测试和本地浏览器检查不能保证所有语言表达、临床情况或机型均无问题。
