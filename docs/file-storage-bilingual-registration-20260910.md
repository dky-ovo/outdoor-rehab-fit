# 文件存储、双语教学视频与注册码更新（2026-09-10）

## 完成范围

- 后台左侧独立“文件存储”，支持任意文件类型、多文件、目录树和空文件夹导入、搜索、分类、分页、全选本页、批量删除、回收站与恢复。
- 文件实际保存到服务器配置的 `MEDIA_UPLOAD_DIR` 持久磁盘。图片/GIF/视频可用于公开教学，其他文件仅授权后台下载；这不是新增的 Google Cloud Storage 桶同步服务。
- 单个图片限制 12 MB，视频及其他文件限制 250 MB。被教学内容引用的文件不能删除或归档；同名文件不覆盖原件。
- 设施媒体编辑取消手动 HTTPS 输入，提供“从电脑导入”和“后台现有云端存储”，中文、英文教学视频分别维护。
- 各后台长列表分页；用户、科研原始数据、日志等由服务端分页，客户端列表也提供翻页按钮。搜索后回到第一页，删除末页内容后校正页码。CSV 导出不局限于当前页，超过 50,000 条明确拒绝并要求缩小范围。
- 用户管理新增“用户注册”：后台输入姓名、手机号、参与者/治疗师类型并生成随机注册码。APP 填昵称、手机号、推荐码、密码和确认密码，无需短信步骤。
- 推荐码绑定手机号及服务器指定类型，一次性使用、可停用，完整码仅生成时显示一次，数据库只保存哈希。治疗师使用现有项目人员 APP 功能，不自动获得后台权限。已有账号登录及访客访问不变。
