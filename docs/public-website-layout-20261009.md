## 实际采用的改写提示词

> 优化「戶外健體樂」研究官网，保留繁体中文、酒红/金色/青绿色品牌和所有研究内容。让导航与正文共享按屏宽变化的容器；大屏充分利用横向空间，首屏按视口高度安排，平板和手机按内容切换列数。放大文字与器材视觉，使二者保持均衡。工作坊卡片使用柔和的品牌色边框和短距离渐入；联系区域加入轻微半透明层次。资源页采用宽幅图文卡片，文章页使用易读正文与完整配图双栏，小屏堆叠。人物、手机截图和论文图片保持原始比例；保留教授和合作伙伴链接，以及李欣迪的既有信息。支持键盘导航和减少动态效果偏好，不增加远程素材或运行依赖。

## 具体实现

- 新增 `website/layout.css`，六页统一加载；`site.js` 使用本次版本参数刷新浏览器缓存。
- 正文和导航的左右边距统一为 `clamp(18px, 4vw, 112px)`，超宽布局上限 2240px；1920px 视口实测正文约 1751px（含浏览器滚动条），原为 1160px。
- 首页首屏使用可视高度，标题、说明、按钮、工作坊信息与器材图组合；背景光晕与有限次数的轻微漂浮强化层次。
- 介绍、应用、AI、研究成效、合作伙伴及页尾采用对应的比例列，清除造成空白的固定最小高度。
- 文章正文与配图分离，大屏双栏、小屏单栏；修正两张研究图片的固有尺寸，资源封面用 contain 完整显示。
- 手机截图按 367:700 预留空间，避免加载前高度塌陷；人物头像使用 contain。
- 保留主导航菜单、返回顶部、阅读进度；卡片渐入错开最多 165ms，键盘焦点可立即显示，减少动态效果模式禁用动画。
- 修复锚点双重顶部偏移、小屏步骤正文过窄和对比圆标定位问题。
- 短页面通过页面级 flex 布局把页脚推至屏幕下方。
