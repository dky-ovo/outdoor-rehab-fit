# 后台易用性与布局优化（2026-09-23）

## 范围

本轮沿用现有后台、API、数据库、权限和 SVAR 文件库，不迁移管理系统、不更改 APP 教学内容、不导入第三方模板依赖。部署仅替换网页静态资源，不重启 API、不修改数据库或上传文件；未发布手机 OTA 或新安装包。

## 参考与采用方式

- [Strapi Content Manager](https://docs.strapi.io/cms/features/content-manager)：列表检索与单项编辑分离、字段分组和明确的编辑操作。用于设施列表筛选与分组编辑器。
- [Directus Collection Page](https://docs.directus.io/user-guide/content-module/content/collections)：内容搜索、条件筛选和排序。用于首页内容、设施教学、设施位置三组本地视图筛选，不改变存储数据。
- [Ant Design Data Display](https://ant.design/docs/spec/data-display/)：按信息重要程度组织显示，照顾长文字、空状态和表格操作。用于导航、卡片、反馈和窄屏布局。

以上是交互参考，未安装、复制整个 Strapi / Directus 系统，也没有新增许可费用。

## 已实现

1. 主菜单图标按栏目固定绑定，不因账号权限过滤而错位；窄屏保留主导航，顶部操作支持换行。只有设施维护与用户管理显示必要的二级菜单，避免空白侧栏。
2. 数据概览增加按现有权限显示的常用入口：设施教学、首页内容、文件存储、用户反馈。
3. 首页内容、设施、位置列表加入搜索、上下架状态、名称/展示顺序排序、结果计数和清除筛选；更改筛选后分页回到第一页。
4. 设施编辑器分为基本信息、图片/GIF/中英视频、双语教学。教学再按使用说明、运动学、物理治疗、职业治疗、中医及志愿者提示切换；所有原字段及权限保留。
5. 编辑器固定保存/取消/错误区域；未保存退出需确认；保存时锁定操作，迟到的媒体选择不会写入其他器材草稿。上传文件不会因放弃表单而删除。
6. 设施保存成功但列表刷新失败时明确提示“已保存”，避免重复创建，并提供重试。
7. 单一数据栏目的加载故障不再伪装成密码错误或阻断整个登录。失败栏目禁止编辑旧默认值；访客、注册码等独立子页不被注册用户列表的故障阻断。401 仍拒绝登录。
8. 反馈标题、电邮、按钮支持换行；卡片白底包含整个内容；分页按钮扩大触点并在边界阻止无效请求。
9. 文件库工具栏和筛选框按可用空间换行；目录树和表格仅在文件库内部横向滚动，不撑宽整个后台；用户/科研表格有局部横向滚动。
10. 真实浏览器复现并修复 SVAR 表格双击错选下一行：在鼠标按下捕获阶段先以 `preventScroll` 聚焦表格，避免组件后续聚焦导致嵌套滚动。未改变文件身份、排序、选中规则或权限；列表进入文件夹、文件预览、返回上级均重新点击验证成功。

## 管理员常用流程

1. 从概览进入“编辑设施教学”，搜索编号或名称，按上下架状态筛选。
2. 点击编辑，在对应页签修改内容；双语教学内选择栏目，核对中英文后保存。
3. 图片/视频仍从电脑上传或从现有文件存储选择；整理文件夹不改变已有视频地址。
4. 保存成功后，APP 下次刷新设施教学会读取服务器内容；本轮后台界面修改不要求手机 OTA。
5. 用户反馈可按状态筛选、逐页查看并添加内部备注；只读操作员不能修改处理记录。
