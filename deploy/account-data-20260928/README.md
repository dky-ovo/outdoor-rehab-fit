# 帐户资料同步 v10

此增量更新要求线上 API 为 `outdoor-fit-api:20260928-v9`。新增 `account_documents` 表，生产库从 40 张表变为 41 张表；不重新导入数据库，不移动图片视频，不修改当前域名或 RDS 配置。运行 `python3 install.py`，按提示输入迁移账号的 RDS 密码。密码只通过标准输入传递。

AI 中英文历史、训练目标、SMART 目标、使用统计和语言选择按账号同步。既有运动记录及日记增加后台同步，学习证据增加跨设备下载，姓名头像定期刷新。游客资料、图片缓存、凭据和正在进行的计时仍属于设备本地。

登录、回到前台及使用期间自动同步，设置页可查看和重试。首次更新会上传旧设备本地历史；因此请先更新原手机并联网打开，再查看另一设备。历史对话在 AI 历史记录中查看，不会替换正在输入的新对话。新的后台 AI 结果会直接保存云端，任务七天清理规则不再影响新历史记录。已卸载或清除存储而从未上传的旧历史无法恢复。

每项记录有服务端版本和操作编号。AI 消息按 ID 合并，删除使用墓碑记录防止旧设备复活；目标等单项冲突保留先被服务端接受的版本，独立项目分别同步；离线变化持久化后续传。使用统计按设备分量累加、同一分量按最大计数合并；学习覆盖区间合并，下载不会伪造新的科研事件。账号删除同时清理新表资料。

包仅携带变化的网页资源，未变化资源从当前网站目录按 SHA-256 核验后复制。安装前验证包、Compose、运行镜像和挂载目录；构建候选镜像及兼容回退镜像，再建表并切换。检查 API 健康、管理员网页、App 网页和新增接口。切换容器可能短暂断开连接。安装不会发布 Android OTA。

失败恢复原服务；回退保留新增表及资料。兼容回退脚本：`/opt/outdoor-fit/production/.update-state/account-data-20260928-v10/rollback.sh`。不要直接重启原始 v9 镜像（其只接受 40 张表），也不要重跑旧 SQLite 迁移。SSH 中断先检查容器及上述状态目录，不要删除状态后重复安装。

后端部署成功后发布对应 v10 Android Build17 OTA。旧 v9 手机仍可使用既有功能；新同步能力要求手机更新到 v10。此版本沿用单 API 实例的 AI 队列，不扩展为多个同时运行的 API 副本。
