# AI 任务与账号收藏：20260928-v9

包内包含后端源码、网页导出、新增两张 RDS 表的迁移和安装程序。现有用户、科研、图片和视频数据不重导。Caddy 的域名、证书和端口配置沿用正在运行的容器；只把网站静态目录切换到此次导出。官网域名不新增路由。

交付使用 `-delta.tar.gz` 包：网页只携带改变的文件；其余从运行中 Caddy 的网站目录按 SHA-256 校验并复制。新网站目录只包含本次完整清单内的文件，不沿用已移除的内置旧照片。缺失或校验不符会在构建及数据库迁移前停止。

在阿里 ECS 解压后的包目录执行 `python3 install.py`。程序先核对包校验和、运行中的 Compose 配置和镜像，再构建候选镜像与兼容回退镜像。随后在终端输入 `outdoor_fit_migrator` 的 RDS 密码，新增 `account_bookmarks` 和 `assistant_jobs` 两张表。密码只通过标准输入交给临时容器，不写文件、不放在命令行。该账号需已具备 outdoor_fit_prod 的建表权限。

切换 API 和 Caddy 会造成短暂连接中断。安装会检查内部 API、正式 HTTPS API 和网页正文；失败时恢复旧服务。记录及回退脚本保存在 `/opt/outdoor-fit/production/.update-state/account-continuity-20260928-v9/`。如果 SSH 中断，先查看容器状态，再运行其中的 `rollback.sh` 可恢复兼容旧代码；不要再次盲目执行安装或删除状态目录。

迁移只新增表，回退不会删除新表及已同步的数据。旧程序有“必须恰好 38 张表”的启动限制，包内提前构建的回退镜像仅为旧代码放宽至 38–40 张表。不要直接使用原 v2/v4 镜像重启，也不要重新运行旧版 SQLite 导入/结构校验工具。

后台任务当前面向现有单 API 实例：短 POST 返回任务编号，RDS 保留状态与结果，生成不依赖手机连接。生产启动恢复排队任务；异常中断的运行中任务标记失败，不自动重试付费调用。不得把此版本部署成多个同时运行的 API 副本。正常关闭等待当前任务，未开始任务保留至下一次启动。结果保留七天，在启动及后续提交时清理；账号删除时同时清理收藏和任务。

收藏以账号 ID 在 RDS 存储，每项有版本及取消收藏记录。客户端本地缓存立即呈现、离线改动保留，网络恢复后按项目合并；重复请求和多设备冲突不会全量覆盖收藏。首次迁移以已有云端记录优先，游客数据不上传。

安装成功后，继续执行 `docs/android-build17-account-continuity-v9-ota.md` 中的手机发布命令。网页更新随此包部署；不需要手机 APK 重装。
